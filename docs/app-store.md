```
第二種電気工事士をめざす、電気の知識ゼロの人のための学習ゲームです。
中学理科の「電流・電圧・抵抗」の復習から始めて、試験に出る電気理論、配線図、施工方法、法令まで、1回5〜10分のセッションで少しずつ積み上げます。

【読んで、すぐ解く】
説明を数ページ読んだら、その場で問題。読みっぱなしにならず、いま覚えたことをすぐ確かめられます。
直列・並列の回路図、オームの法則の三角形、単線図などの図も、本文の数値に合わせて用意しています。

【600問以上の問題】
・過去の筆記試験の出題傾向を分析して作った、オリジナルの試験型問題
・計算問題は数値が毎回変わるので、答えを丸暗記せず解き方が身につく
・4択、○×、数値入力の3つの出題形式
・ヒントと解説つき。一部の問題には、英語での語源や現場の豆知識も

【忘れる前に、もう一度】
間違えた問題は、1日後・3日後・7日後・14日後に自動で出題されます。
正解するたびに次の出題までの間が伸び、14日後に正解すれば卒業。苦手な問題だけを効率よく繰り返せます。

【単元の最後はボス戦】
単元の仕上げは、制限時間つきのボス戦。速く正確に答えるほど大ダメージで、3秒以内ならクリティカル。
連続正解でコンボがつながり、倒せばノーミスと速さでランクがつきます。取りこぼした問題は、その場で解説つきで見直せます。
12体の電気モンスターを倒して、ボス図鑑を埋めましょう。

【勉強した時間が見える】
学習時間の目標200時間までをゲージで表示。150時間の安心ラインを超え、200時間を超えるとゲージがあふれ出します。
ホームには前の日に学んだことのまとめが出るので、続きからすぐ始められます。

【収録内容】
・電気の基礎（中学理科の復習、オームの法則、直列・並列回路、電力、電線の抵抗、電圧降下）

・配電理論と配線設計（電圧降下と電力損失、許容電流、幹線、分岐回路）

・配線図（最少電線本数、リングスリーブと差込形コネクタの数）
・施工方法、接地工事、検査、法令
・技能試験の基礎（リングスリーブの選び方、施工手順と欠陥の見分け方）
```

## キーワード（100 文字まで・半角カンマ区切り）

名前とサブタイトルに入っている語（でんきクエスト、第二種電気工事士、電工二種、学習ゲーム、ボス）は、
App Store が自動で検索対象にするので入れていない。

```
二種,電工,資格,国家資格,筆記試験,技能試験,電気理論,配線図,複線図,単線図,オームの法則,問題集,試験対策,勉強,独学,暗記,計算,理科,電気,工事,法令,リングスリーブ,電圧降下,クイズ
```

「過去問」はキーワードに入れていない。実際の試験問題は収録していないので、
検索語にすると審査で「内容と関係のないキーワード」と判断されるおそれがある。
