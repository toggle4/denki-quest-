# カリキュラム設計書 — 第二種電気工事士 学習ゲーム

## 設計思想

### 1. 基礎は2本立て
- **計算の土台**：オームの法則から三相交流まで。公式暗記ではなく「数字を変えても解ける」状態を目指す。
- **安全の理屈**：施工方法・法令・検査の知識は「感電・火災・漏電を防ぐため」という一本の理由で貫かれている。理由から覚えれば数字を変えた練習と同じ定着効果がある。

### 2. パラメータ化ドリル
計算問題は固定の問題文ではなく、**テンプレート＋変数**として持つ。アプリが毎回数値を変えて生成するため、同じ構造の問題を無限に練習できる。各テンプレートは4段階の変化をつける。

| レベル | 変化の内容 | 例（オームの法則） |
|---|---|---|
| L1 | 数字が素直、求めるものが1つ | 100V・20Ω → 電流は？ |
| L2 | 単位変換・小数・分数が入る | 200V・2.5A → 抵抗は？ / 500mA を A に |
| L3 | 逆算・比の考え方 | 電圧2倍・抵抗4倍 → 電流は何倍？ |
| L4 | 試験形式（回路図つき四択） | 実際の出題パターンそのまま |

### 3. マスタリー基準
単元クリアは「問題を1回解いた」ではなく **「直近10問で正答率90%以上」** など、安定して解ける状態で判定する。基礎ステージはこの基準を厳しめ（95%）にする。

### 4. スパイラル復習
上位ステージに進んでも、日々のセッションに基礎ステージの問題が一定割合（例：20%）混ざる。間違えた問題は 1日→3日→7日→14日 後に再出題。

### 5. 集中を切らさない
- 1セッション 5〜10 分（問題数で区切る）
- 正解連続でコンボ、単元末にボス戦（制限時間つき）
- 説明は「1画面1概念」、読ませすぎない。図で見せる。

## ステージ0：電気の基礎（12単元）

> 目標：数字や聞き方が変わっても、迷わず式が立てられる。

### F01 数と単位の足場
- 単位記号：V, A, Ω, W, Wh, Hz, m, mm²
- 接頭語：k（1000）、m（1/1000）、μ（1/100万）の相互変換
- 小数・分数・パーセントの計算、√2・√3 の概算値（1.41・1.73）
- 有効数字の丸め方（試験の選択肢に合わせる）
- **ドリル**：kW↔W、mA↔A、mm²の読み、√3×200 の概算
- **なぜ必要か**：試験の計算ミスの半分は単位変換で起きる

### F02 電流・電圧・抵抗とオームの法則
- 電流＝流れる量、電圧＝押す力、抵抗＝流れにくさ（水路のたとえ）
- V = IR の3つの形
- **ドリル**：L1〜L4、数値ランダム
- **橋渡し**：電線にも抵抗がある（F07へ）

### F03 直列回路
- 電流はどこも同じ、電圧は抵抗の大きさに比例して分かれる
- 合成抵抗 = 足し算
- **ドリル**：分圧、合成抵抗、各抵抗の電圧を求める

### F04 並列回路
- 電圧はどこも同じ、電流は抵抗の小ささに比例して分かれる
- 合成抵抗 = 和分の積（2本）、一般式
- **ドリル**：分流、同じ抵抗n本の合成、抵抗を1本外すと電流はどうなるか

### F05 直並列の混合回路
- 「並列の塊を1本にまとめてから直列」の手順
- ブリッジ回路の平衡条件（試験頻出）
- **ドリル**：回路図をランダム生成し、合成抵抗・指定箇所の電流電圧を求める

### F06 電力・電力量・発熱
- P = VI = I²R = V²/R の使い分け
- 電力量 W = Pt、Wh と J の関係
- ジュール熱 Q = I²Rt（発熱は電流の2乗）
- **ドリル**：電熱器の消費電力、1か月の電力量、抵抗器の発熱量
- **なぜ必要か**：許容電流・過負荷の理屈は「I²Rで熱が出る」に尽きる

### F07 抵抗率と電線の抵抗
- R = ρL/A：長い・細いほど抵抗が大きい
- 直径2倍 → 断面積4倍 → 抵抗1/4
- 銅の抵抗率の目安、mm² と直径の換算
- **ドリル**：長さ・太さを変えて抵抗を比較する
- **なぜ必要か**：電線の太さと許容電流の関係の根拠

### F08 電圧降下と電力損失
- 電線の抵抗 × 電流 = 電圧降下（負荷に届く電圧が下がる）
- 電力損失 = I²r
- 単相2線式の往復分（2倍）の考え方
- **ドリル**：電線抵抗と電流から降下・損失を求める、末端電圧を求める
- **橋渡し**：ステージ4の配電理論に直結

### F09 交流の基礎
- 直流と交流の違い、周波数（50/60Hz）と周期
- 最大値・実効値・平均値、実効値 = 最大値/√2
- 位相のずれ（波形の図で見せる）
- **ドリル**：最大値↔実効値、周波数↔周期

### F10 磁気と電磁誘導
- 電流が流れると磁界ができる（右ねじ）、磁界の中の電線に力（モーター）
- 磁界が変化すると電圧が生じる（発電機・変圧器）
- 変圧器の巻数比と電圧比
- **ドリル**：巻数比の計算、電磁誘導の向きの○×
- **なぜ必要か**：機器の動作原理を「暗記」から「理解」に変える

### F11 交流回路とインピーダンス
- 抵抗 R とリアクタンス X、インピーダンス Z = √(R²+X²)
- 力率 cosθ = R/Z、有効電力 P = VIcosθ、皮相電力 S = VI
- 力率改善（コンデンサ）の意味
- **ドリル**：R-L直列回路の Z・I・P・力率、力率から有効電力を求める

### F12 三相交流
- 三相の利点（電線が少なくて済む、モーターが回る）
- Y結線・Δ結線の線間電圧・相電圧・線電流・相電流（√3の関係）
- 三相電力 P = √3 × VI cosθ
- **ドリル**：結線ごとの電圧電流の換算、三相電力、1線が断線したときの電流
- **ボス戦（ステージ0 総合）**：F02〜F12 からランダムに10問、制限時間つき

## 進行ルール（アプリ側の仕様）

1. **アンロック**：ステージ0はF01から順に。ステージ1はステージ0のF01〜F06クリアで解放（暗記系を早めに始めるため、F07以降と並行可能）。
2. **日次セッション**：新規単元の問題 60% ＋ 復習（間隔反復）30% ＋ 基礎ドリル（ステージ0からランダム）10%。
3. **弱点検知**：同じテンプレートでL2以上を3回連続で間違えたら、L1に自動で戻して足場を組み直す。
4. **模擬試験モード**：ステージ2まで到達したら解放。50問・120分の本番形式。カテゴリ別の正答率を表示し、弱い単元へリンク。
5. **図解ライブラリ**：全単元の概念図・回路図・器具画像を一覧で見返せる辞書機能（網羅性の担保）。

## 教材データの構成（Claude Code への指示）

- `content/units/<stage>_<id>.json`：単元ごと。固定問題（`multipleChoice` 等）と、**テンプレート問題（`template`）** を混在させる。
- テンプレート問題は `variables`（範囲つき乱数）と `answerFormula` を持ち、アプリ側で数値を生成して正解を計算する。詳細は `content/schema.md`。
- 図記号・器具画像は `Assets` に SVG で置き、JSON からは名前で参照する。
