# content/lessons/ — インプット教材（テキストビュー）の仕様

## ファイル構成
- 単元ごとに1ファイル：`content/lessons/<unitId>.md`（例：`F02.md`）
- 問題データ `content/units/<unitId>.json` と同じ unitId で対応づける

## Markdown の約束事（アプリのパーサが解釈する）
| 記法 | 意味 |
|---|---|
| `# タイトル` | 単元タイトル（ファイル先頭に1つ） |
| `> 目標：…` | 単元の到達目標（単元の最初の画面に表示） |
| `## セッション N：タイトル` | セッションの区切り。1セッション = 説明と問題が交互に並ぶ1回分（5〜8分） |
| `---` | 画面の区切り。**1画面1概念**。スワイプで次へ |
| `<!-- figure: 名前 -->` | 図を挿入する位置。`Assets/figures/<名前>.svg` を表示 |
| `**例題**` から次の `---` まで | 例題ブロック。解き方を段階表示（タップで1行ずつ開く） |
| `**まとめ**` | 画面の下部にカード表示 |
| `> ⚠️ …` | よくある間違い（注意カード） |
| `> 🔌 …` | 電気工事士試験とのつながり（橋渡しカード） |
| `<!-- quiz: id, id -->` | **差し込み問題**。直前の説明画面のあとに、`content/units/<unitId>.json` の該当 id の問題を順に出す |
| `<!-- session-quiz: id, … -->` | **セッション末のまとめ問題**。セッションの最後に出す |

## 画面の流れ（説明と問題を混ぜる）
1. 単元マップ → 単元を選ぶ → セッション1から順に開始
2. セッション内は「説明画面 → 差し込み問題 → 説明画面 → 差し込み問題 → … → まとめ問題」の一本道
3. 差し込み問題は「いま読んだ概念だけ」を問う。1〜2問
4. 正解：解説を短く表示して次の説明画面へ。不正解：解説を表示し、同じ問題（template なら数値を変えて）を再出題。2回連続不正解なら正解を示して先へ進む（詰まらせない）
5. セッション末のまとめ問題で正答率80%未満なら、そのセッションを「要復習」にして、次回セッション開始時に先にもう一度出す

## 戻る・進むのルール
- **説明画面**の間は前後に自由にスワイプできる
- **問題画面**に入ったら、前の説明画面には戻れない（戻るボタンを出さない）。解説は問題の `explanation` のみ
- 問題を終えて次の説明画面に進んだら、そこからまた説明画面の間は自由に戻れる。ただし直前に終えた問題画面より前には戻れない
- セッションを途中で閉じたら、次回は「最後に終えた問題画面の直後」から再開する
- 読み直したいときは単元マップ → 単元 → セッション一覧から、既読セッションを最初から開き直せる（このときは説明のみを表示し、差し込み問題は出さない「復習モード」）

## 単元クリアの条件
- 全セッションのまとめ問題を通過し、単元末のボス戦（`content/units/<unitId>.json` の `boss`）をクリア
- クリアで次の単元が解放される（順序は docs/curriculum.md）
